# Hackathon deliverables checklist

From Daytona HackSprint w/ Arize AI — NYC, October 2026.

- [ ] Public GitHub repository URL
- [ ] Devpost submission before deadline
- [ ] Team name + all members with emails/socials
- [ ] Demo video under 2 minutes
- [ ] Project description: 2–3 sentence summary
- [ ] Problem + impact
- [ ] Technical architecture
- [ ] Sponsor tools used: Daytona, Arize, AWS Bedrock, SurrealDB (+ optional ElevenLabs)
- [ ] Pitch: 3 minutes + 2 minutes Q&A if finalist

## Pitch honesty

- Savings = claims users could file free themselves
- Value = agent does paperwork in business language with evidence
- Synthetic identities only
- Not legal/tax advice
- Distinguish `PAYMENT_ISSUED` vs `PAYMENT_CONFIRMED`
